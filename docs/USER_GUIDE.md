## 安装与更新

### 步骤 1：安装用户脚本管理器

请根据您使用的浏览器安装主流的用户脚本管理器：

- **Google Chrome / Microsoft Edge**：安装 [Tampermonkey (篡改猴)](https://www.tampermonkey.net/)
- **Firefox**：安装 [Tampermonkey](https://addons.mozilla.org/zh-CN/firefox/addon/tampermonkey/)
- **Safari**：安装 [Userscripts](https://apps.apple.com/app/userscripts/id1463298887)

### 步骤 2：安装或更新 Fab Helper 脚本

1. 在项目根目录下执行打包构建（或从发布页获取最新的 `dist/fab_helper.user.js`）：
   ```bash
   npm run build
   ```
2. 打开脚本管理器控制面板，选择“添加新脚本”（或选择已有脚本进行编辑）。
3. 将 `dist/fab_helper.user.js` 的全部内容粘贴到编辑器中，并按快捷键 `Ctrl+S` / `Cmd+S` 保存。
4. 打开 [Fab.com 免费搜索列表页](https://www.fab.com/search?is_free=1&sort_by=-firstPublishedAt)，页面右下角将自动浮现深色玻璃控制面板。

## 核心操作界面（仪表盘）

控制台右下角的控制面板包含三个主要选项卡：**「仪表盘」**、**「设定」** 与 **「调试」**。

### 仪表盘状态指示区

- **📥 待办**：当前排队等待领取入库的商品数量。
- **✅ 已入库**：本地确认已拥有或本次会话中成功添加到 Library 的商品总数。
- **❌ 失败**：处理异常且重试耗尽的商品数量。
- **👁️ 可见**：当前搜索页面上处于渲染可见状态的商品卡片数。
- **🙈 已隐藏**：已被自动隐藏的已拥有商品或付费商品数量。
- **📍 位置**：当前记住的瀑布流游标（Cursor）时间锚点；点击右侧的 **🔄** 可重置浏览位置。

### 常用操作按钮

- **一键开刷 / 停止**：开始执行待办队列中的商品入库，或手动暂停当前正在运行的任务。
- **🔄 同步状态**：强制向 Fab 服务器刷新一次当前视野内商品的拥有状态。
- **🙈 显示已得 / 隐藏已得**：切换是否在搜索结果中隐藏已入库的商品卡片。
- **🔁 重试失败 (N)**：当有失败商品时亮起，点击可将失败商品重新移回待办队列顶部并重新尝试领取。
- **📄 复制日志**：一键将操作日志面板的所有内容复制到系统剪贴板。
- **🗑️ 清空日志**：清空当前日志面板中的条目。

## 设置选项详解

切换到 **「设定」** 选项卡，您可以根据网络环境与使用习惯定制行为：

1. **无限滚动时自动添加任务** (`autoAddOnScroll`)  
   当您手动滚动页面时，一旦页面加载出符合免费条件的未入库新商品，会自动将其加入待办队列。

2. **自动滚动页面（自动扫描全部）** (`autoScroll`)  
   开启后，无需手动操作，脚本会自动平滑逐屏向下滚动，触发全站免费商品的无限分页加载，实现全自动化无人值守全库入库。

3. **记住瀑布流浏览位置** (`rememberScrollPosition`)  
   自动保存最后的浏览深度。页面刷新或重启浏览器后，会自动还原滚动位置并以亮绿色高亮提示，避免从头开始。

4. **429后自动恢复并继续** (`autoResumeAfter429`)  
   当遇到服务器请求限流（HTTP 429）时，脚本会自动进入冷却期，冷却结束后通过轻量探测请求确认状态，一旦解除限速即自动恢复任务执行。

5. **无商品可见时自动刷新** (`autoRefreshEmptyPage`)  
   当搜索列表因隐藏所有已拥有商品而处于空白时，自动刷新并请求下一批内容。

6. **隐藏打折的付费商品** (`hideDiscountedPaid`)  
   过滤原价收费、当前仅有部分折扣的商品，保持列表纯净。

7. **隐藏所有付费商品** (`hidePaid`)  
   强制过滤任何非免费项目。

8. **禁用图片/媒体等大资源** (`blockLargeResources`)  
   在最底层拦截图片、视频及 WebGL 3D 画布的下载，极大提升后台标签页的加载速度并降低系统资源消耗。

9. **人机验证通知** (`Verification notifications`)  
   点击开启浏览器的系统通知权限。授权后，当遇到平台弹出安全人机验证时，会自动推送桌面通知提醒您手动处理。

10. **🗑️ 清空所有存档** (`clearAllData`)  
    清除所有本地记录（待办、已入库、失败、游标历史），恢复到出厂初始状态。

## 人机验证（CAPTCHA）与浏览器通知

在批量领取资产的过程中，Fab.com 或 Epic 平台可能会偶发触发 Cloudflare Turnstile、ArkoseLabs 或真人安全校验。

### 脚本的安全保护机制

1. **绝不秒关窗口**：遇到验证时，Worker 标签页会立刻取消强制超时关闭，保留页面供您操作，并在页面顶部挂上醒目的红色警示条。
2. **自动熔断暂停**：主页面感知到验证后，会立即自动停止派发新任务，防止并发请求招致更严厉的账号封禁。
3. **保留待办不丢弃**：遇阻的任务会自动留在待办队列的最前列，不会被打入失败列表。

### 开启与使用浏览器通知

1. 打开 Fab Helper 面板顶部的 **「设定」** 选项卡；
2. 找到 **「人机验证通知」**，点击 **「开启并测试」**；
3. 浏览器会弹出权限询问，请选择 **“允许”**；
4. 此时会收到一条测试通知：“*Fab Helper：通知已开启*”，表明配置成功；
5. 后续运行中一旦触发人机验证，系统会自动推送通知：“*Fab Helper：需要手动验证*”；
6. **处理验证**：
   - 切换到标题标有 **`⚠️【需验证】`** 的标签页；
   - 在页面中手动勾选完成真人校验；
   - 验证完成后回到 Fab 搜索主页面，点击一次面板底部的 **「一键开刷」**，任务即可顺畅继续执行。

## Bundle 资产与限时免费资产入库机制

### Bundle 资产（资产集合）
Fab 平台上的资产包（Bundle）与普通商品不同，官方不允许直接通过 API 加库，而必须通过官网的原生零元结算页面（`/payment/web/purchase`）。  
Fab Helper 会自动探测 Bundle 资产（无论是 `/bundles/` 链接还是列表中的 `/listings/` 链接），并在 Worker 中自动驱动原生结算 iframe，安全完成零元购买并向服务器双向核对。

### 100% 折扣限时免费
对于原价不为 0（如 $49.99）、但促销期打折至 0 元的限免商品，脚本能自动折算其有效应付价格，识别其为合法免费商品，并精准提取出专属许可进行直接入库。

## 429 限速自动处理与恢复

- **触发表现**：操作日志中显示 `[API入库] 收到 429` 或 `检测到429错误页面`。
- **自动处理**：脚本会自动转入冷静期（通常为 40~60 秒，若服务器提供 `Retry-After` 则依据服务端推荐时间），并暂停派发新任务。
- **自动恢复**：冷静期过后，脚本会在后台发送一条轻量的探测请求；一旦探测成功，状态栏显示 `✅ 恢复探测成功！限速已解除`，并自动接续未完成的任务，无需人工干预。
